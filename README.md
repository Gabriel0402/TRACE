# TRACE

## 视觉语言动作大模型的形式化时序语义增强

**中文** | [English](README_EN.md)

TRACE 研究如何将语言指令中的时序要求转化为可执行的形式规约，并利用显式时序状态引导动作选择。本仓库提供论文配套的项目介绍、结构化时序约束操作基准下载入口与使用说明，方法实现将另行发布。

**Code release soon.** 代码即将发布。数据下载地址与中英文使用说明已提供，见下方数据下载部分。

## 研究背景

机器人操作不仅要求选对对象，还需要遵守动作之间的先后关系、选择一致性和触发响应等约束。例如，将两本书放入书架时，若任务要求先放最高处的书，再放最右侧的书，即使最终两本书都已归位，颠倒顺序仍会导致任务失败。

TRACE 将这些过程要求表示为有限轨迹线性时序逻辑（LTLf）规约，通过自动机记录已经完成的操作和尚待履行的要求，使执行历史能够直接参与下一动作的选择。

## 方法概述

框架由两个模块组成。

### 时序规约归纳

采用编译器优先机制，从任务指令中识别时序结构和语义角色，结合场景对象及候选动作描述完成语义接地，生成可执行的 LTLf 规约。规则匹配失败时，由学习型模型补全。当前实现的主要规约构造能力来自编译器路径。

### 自动机引导控制

将规约转换为确定性有限自动机，并根据逐步发生的动作事件更新自动机状态。控制器屏蔽执行后无法再满足规约的候选动作，再依据到接受状态的距离调整其余动作的排序，以支持剩余任务的完成。

当前实验采用冻结 OpenVLA 表征上的原语动作评分器。不同控制设置共享特征提取器和评分头，读取初始图像、任务指令与文本动作历史；时序引导改变候选动作的选择规则，不更新共享评分器参数。评测在离散原语动作空间中进行。

## 结构化时序约束操作基准

基准覆盖 10 种时序结构类型，包括顺序、容器选择一致性、触发响应和分支等约束。实例将具体操作内容与时序结构分开组织，包含初始场景、任务指令、候选动作语义、参考规约及用于规约检验的正负轨迹。

评测分别考察规约构造质量和下游执行效果，重点关注生成规约是否准确表达任务要求，以及执行轨迹是否满足参考规约。
